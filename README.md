# 奖杯指南 / Trophy Field Guide

[在线使用 / Open in browser](https://xialin99.github.io/makefun-trophy-field-guide/)

## 中文

### 第一次使用

1. [打开奖杯指南](https://xialin99.github.io/makefun-trophy-field-guide/)。从内置示例开始，不用注册。
2. 点击奖杯行查看解锁方法，勾选右侧复选框表示已获得。标题上方的进度计数会更新。
3. 在 **解锁路线** 查看建议顺序。如果要换浏览器或设备，先 **导出 JSON**，到另一台设备点 **导入 JSON**。

离线奖杯清单，支持分类筛选、隐藏剧情内容、浏览解锁路线和导入导出进度。下载后用浏览器打开 `index.html` 即可。内置虚构奖杯示例，数据字段见 `app/data/catalog.js`，路线配置见 `app/guide.js`。

界面默认显示中文，右下角可以切换为 English。

## English

### First use

1. [Open Trophy Field Guide](https://xialin99.github.io/makefun-trophy-field-guide/) and start with the built-in examples.
2. Select a row for its unlock guide. Tick the box on the right to mark it earned. The progress counter updates.
3. Use **Roadmap** for a suggested order. **Export JSON** before switching devices, then use **Import JSON** on the other device.

An offline achievement checklist with category filters, spoiler controls, a roadmap, and JSON backups. Download the project and open `index.html` in a browser. It ships with fictional trophies. Customize the catalog in `app/data/catalog.js` and the roadmap in `app/guide.js`.

The interface starts in Simplified Chinese. Change the language in the lower right.
